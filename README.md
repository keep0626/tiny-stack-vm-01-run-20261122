A tiny stack virtual machine for make.fun's tiny stack ISA v1: 32-bit wrapping integers, a 256-value data stack, a 64-deep call stack, 256 words of memory, input/output, and traps 2-11 with their exit codes.

Run: `node main.ts` (Node 22). It reads `/input/i001` … `/input/i040` (`program.bin` + `input.bin` each) and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` for every instance.
